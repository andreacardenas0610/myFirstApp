Este proyecto utiliza **React** junto con **Vite**, ofreciendo un entorno de desarrollo rápido y ligero con soporte para Hot Module Replacement (HMR) y configuración básica de ESLint. Vite cuenta con dos plugins oficiales para trabajar con React: **@vitejs/plugin-react**, que utiliza Babel (u oxc en algunos entornos), y **@vitejs/plugin-react-swc**, que emplea SWC para un mejor rendimiento. Para proyectos orientados a producción se recomienda el uso de TypeScript y reglas avanzadas de linting con `typescript-eslint`.

El proyecto corresponde al Taller 2 y consiste en una aplicación desarrollada en React cuyo objetivo es demostrar el uso de componentes y props dentro de una estructura organizada y modular. La interfaz está compuesta por cuatro secciones principales: un Header con el título del proyecto, una sección Props donde se ejemplifica el envío de datos desde un componente padre hacia un componente hijo, un Content que simula un carrito de compras mostrando productos y precios, y un Footer con información complementaria. Todos estos componentes se organizan desde `App.jsx`, que funciona como componente raíz.

La aplicación permite aplicar conceptos fundamentales como la creación de componentes reutilizables, la comunicación mediante props, el renderizado dinámico y la separación del código en archivos independientes para facilitar el mantenimiento, la claridad y la escalabilidad. Además, incluye un ejemplo práctico con datos de un automóvil (marca, modelo, año, color y precio) enviados como props, reforzando la idea de que las props son de solo lectura y no deben modificarse directamente en el componente hijo. En conjunto, el proyecto sirve como base para comprender los fundamentos de React y deja preparada la estructura para futuras mejoras con estados y lógica más avanzada.
